# Workflows n8n

Mes workflows n8n, exportés tels qu'ils tournent, un dossier par projet.

| Dossier | Projet | Workflows |
|---|---|---|
| [`rag-naval/`](rag-naval/) | **Chatbot RAG** sur *The Almanack of Naval Ravikant* : ingestion du livre, recherche hybride, reranking, réponses sourcées | 4 |
| [`recap-quotidien/`](recap-quotidien/) | Récap Telegram du matin : rendez-vous et mails à traiter sur 3 comptes, avec boutons d'action | 3 |
| [`cours/`](cours/) | Exercices faits en cours | 2 |

**Importer un workflow** : dans n8n, *Create workflow › ⋯ › Import from File*, puis recréer les credentials.
Les exports ne contiennent ni clé d'API ni identifiant de credential ; les adresses et identifiants personnels sont remplacés par des valeurs à renseigner.
